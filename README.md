# Escola de Idiomas
Projeto Final de Laboratório de Banco de Dados


Desenvolvimento do modelo e da infraestrutura de banco de dados para uma escola de idiomas com cursos presenciais de inglês, espanhol e francês, organizados em seis níveis (de A1 a C2). 

O sistema implementa o domínio acadêmico delimitado pelas 21 regras de negócio da equipa, abrangendo:
* **Pessoas e Papéis:** Tabela central de pessoas identificadas por CPF, com especialização para Alunos e Professores.
* **Estrutura e Aulas:** Gestão de turmas por idioma e nível, com registo de aulas, conteúdos e frequências.
* **Matrículas e Auditoria:** Controlo de vagas, estados de matrícula (ativa, trancada, concluída, cancelada) e histórico temporal de alterações.
* **Avaliação e Certificação:** Avaliação por competências com exigência de frequência mínima de 80% e nota ≥ 6,0 para a emissão de certificados digitais com código único.
* **Mentoria:** Acompanhamento extraclasse entre alunos com nota ≥ 7,0 no idioma correspondente.
